Прототип игры «Пинг-понг»

Добро пожаловать в репозиторий с прототипом мультиплеерной игры «Пинг-понг»! Этот проект создан для развлечения и демонстрации базовых возможностей работы с графикой и управлением в реальном времени.

Описание проекта
Это мультиплеерная игра, в которой два игрока соревнуются, отбивая мяч ракетками. Цель — забить мяч на сторону противника и набрать очки.

Технологии
Игра реализована на языке Python с использованием библиотеки Pygame. Pygame предоставляет инструменты для работы с графикой, звуком и управлением, что сделало разработку игры более простой и эффективной.

Управление
Игрок 1 управляет левой ракеткой с помощью клавиш:
Вверх — перемещение ракетки вверх.
Вниз — перемещение ракетки вниз.
Игрок 2 управляет правой ракеткой с помощью клавиш:
W — перемещение ракетки вверх.
S — перемещение ракетки вниз.
Как запустить игру
Убедитесь, что у вас установлен Python (версия 3.x).
Установите библиотеку Pygame, выполнив команду в терминале:
text
pip install pygame
Клонируйте репозиторий на свой компьютер:
text
git clone [ссылка на репозиторий]
Перейдите в папку с проектом и запустите основной файл игры (например, main.py):
text
python main.py
Структура проекта
main.py — основной файл, запускающий игру.
assets/ — папка с ресурсами (изображения, звуки).
README.md — этот файл с инструкцией.
